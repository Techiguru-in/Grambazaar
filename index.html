📖 Student Setup Guide (प्रोजेक्ट कैसे चलाएं)

1. Folder कैसे बनाएं (Create Folder)

अपने कंप्यूटर (Desktop या Documents) पर एक नया Folder बनाएं, जैसे कि: school-ai-chatbot

2. तीनों Files कैसे बनाएं (Create 3 Files)

Notepad या VS Code खोलें और उस फोल्डर में 3 अलग-अलग files बनाएं:

  • index.html - वेबसाइट का स्ट्रक्चर
  • style.css - डिज़ाइन और कलर्स
  • script.js - Groq API और चैट फंक्शनैलिटी

3. Groq API Key कहाँ डालें (Where to put API Key)

Groq Console (console.groq.com) से फ्री API Key बनाएं। आप इसे ऊपर दिए गए "Groq API Key" बॉक्स में सीधे पेस्ट करके Save Key कर सकते हैं, या script.js की पहली लाइन में const GROQ_API_KEY = "gsk_..."; में लिख सकते हैं।

4. Website कैसे चलाएं (How to Run)

index.html फाइल पर डबल क्लिक करें! यह सीधे Chrome, Edge, या Firefox ब्राउज़र में खुल जाएगी। किसी सर्वर या इंस्टॉलेशन की ज़रूरत नहीं है।

5. GitHub Pages पर Free Host कैसे करें (How to Host)

  1. GitHub.com पर नया public repository बनाएं (e.g. my-school-ai).
  2. ये तीनों files (index.html, style.css, script.js) upload करें।
  3. Repository के Settings → Pages में जाएं।
  4. Branch में main / root चुनकर Save करें। 2 मिनट में आपकी लाइव वेबसाइट लिंक तैयार हो जाएगी!

⚠️ Frontend में API Key रखने की Security Limitation

ध्यान दें (Important Warning): जब हम ब्राउज़र में JavaScript (Frontend) में API Key रखते हैं, तो कोई भी छात्र या यूजर ब्राउज़र में "Inspect Element" या "View Source" दबाकर उस Key को देख सकता है। यह प्रोजेक्ट सिर्फ सीखने और स्कूल प्रोजेक्ट्स/डेमो के लिए है। असली पब्लिक प्रोडक्शन ऐप्स में हमेशा एक Backend Server (जैसे Python या Node.js) का उपयोग करके API Key को छुपाया जाता है।
